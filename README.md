# ✨ Настроение

Небольшое адаптивное веб-приложение для поднятия настроения.

## Возможности
- случайные добрые сообщения;
- цитаты и мини-челленджи;
- интерактивный индикатор настроения;
- переключение светлой/тёмной темы;
- адаптивный дизайн для телефона и компьютера.

Открывается прямо как обычный `index.html` — без серверной части и зависимостей.
